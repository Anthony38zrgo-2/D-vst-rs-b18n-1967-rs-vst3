# Impulsos de gabinete (IR)

- **No se inventa** una IR histórica ni se distribuyen capturas de terceros sin licencia.
- Para el MVP la IR es opcional y, si se usa, debe identificarse como «IR externa/medida»
  con su procedencia y licencia.
- Una IR no sustituye la caracterización eléctrica del altavoz: la impedancia compleja
  vista por el transformador es otra medición (véase `docs/MEASUREMENT_PROTOCOL.md`).
