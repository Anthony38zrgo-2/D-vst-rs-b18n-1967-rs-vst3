# Referencias doradas

Salidas verificadas contra una fuente independiente (SPICE, mediciones o hardware real).

Reglas:

- **No** colocar aquí WAV «inventados» que provengan del propio DSP: una referencia
  generada por la misma implementación no valida fidelidad física.
- Cada golden debe acompañarse de: procedencia, condiciones de medida/simulación,
  configuración de parámetros y tolerancia acordada.
- Las referencias SPICE se documentan en `docs/MEASUREMENT_PROTOCOL.md`.
